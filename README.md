# SemanticSearch-Chatbot

A simple yet powerful chatbot built with **NLP** and **semantic search** techniques.  
The project uses **FAISS** for efficient vector similarity search and **SentenceTransformers** to create embeddings for natural language queries.  
The interface is powered by **Gradio**, making it easy to interact with the chatbot directly in Google Colab.

---

## 🚀 Features
- **Semantic search**: Finds the most relevant answers based on meaning, not just keywords.  
- **FAISS integration**: Scalable similarity search for embeddings.  
- **NLP-based embeddings**: Uses the `all-MiniLM-L6-v2` model from Hugging Face’s `sentence-transformers`.  
- **Interactive UI**: Built with Gradio, customizable and easy to extend.  
- **Colab-friendly**: Fully runnable inside Google Colab.
